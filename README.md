✈️ 航班专注管理器 (Flight Concentrator)
“在这个信息过载、注意力被无限切割的时代，一段完整的、不被打扰的时光，已经成为我们最昂贵的数字奢侈品。”
Flight Concentrator (航班专注管理器) 并非又一款枯燥的“番茄钟”或打卡工具。它是一款基于 HarmonyOS (鸿蒙) 原生 ArkTS 开发的航空主题沉浸式专注应用。我们将抵御诱惑、保持专注的枯燥过程，巧妙地重构为一场场跨越云端、经营大型航空公司的宏大旅程。在这里，你的每一次心无旁骛，都是一次从地平线跃入平流层的起飞。
￼
🌟 核心业务蓝图 (Core Scenarios & Features)
本应用建立了一个严密的“时间投入-模拟经营”正向反馈闭环，将用户的学习与工作计划映射为航空公司的调度任务：
🗓️ 1. 全局视角的航程日历与任务分发
抛弃了简单的原生时间选择器，我们从零构建了完全定制化的交互式日历组件。
• 跨日规划：用户可以点击日历网格，自由规划未来每一天的航班（专注任务）。
• 精准调度：输入专注事项（如：“阅读《算法导论》”），并通过军用级时间滚轮精确设定起降（起止）时间。
🗺️ 2. 真实民航数据驱动的动态航线匹配
你的专注时间，决定了你能飞多远。
• 原生数据字典：底层嵌装了全国 50 个核心枢纽机场（含 IATA 代码与真实坐标）的标准飞行时长数据字典。
• 智能过滤系统：系统会自动计算设定的起止时间差，并在 ±40 分钟的弹性阈值内，为你筛选出可执飞的目的地（例如：设定专注 140 分钟，系统将为你匹配飞行时长约 135 分钟的“上海浦东 PVG”或 145 分钟的“成都天府 TFU”）。
🚀 3. 史诗级机队养成与算力博弈
专注不仅积累时间，更创造商业价值。我们收录了多达 36 款 真实世界的传奇客机：
• 全系列厂牌：涵盖中国商飞 (COMAC) C919、波音 (Boeing) 737/747/777/787 家族、空客 (Airbus) A320/A350/A380 全系。
• 收益杠杆机制 (Multiplier)：不同机型拥有专属的“收益系数”。轻型支线客机（如 ARJ21）系数为 1.0，而双层巨无霸 A380 系数高达 4.0。这就要求用户不仅要专注，还要通过专注积攒的资金去购买重型客机，以实现每次专注时间带来的“资金收益”最大化。
⏳ 4. HUD 沉浸式高空飞行与惩罚机制
• 心流模式：进入执飞状态后，界面切换为类似飞机驾驶舱 HUD（平视显示器）的深邃环形倒计时。
• 紧急返航：专注是不可逆的契约。一旦用户中途点击“紧急返航”打断倒计时，本次航程将被立刻销毁，无法获得任何航线解锁和资金收益，以此倒逼用户保持自律。

💻 核心代码架构与技术实现 (Technical Architecture)
本项目采用 HarmonyOS 的 ArkUI 声明式编程范式，并在单页面内实现了复杂的应用状态机与混合渲染，展现了极强的工程化思维。
1. 基于 @State 的轻量级路由引擎状态机
由于业务流转紧密（日历 -> 任务 -> 地图选点 -> 选机型 -> 调度表 -> 执飞），采用传统的 router.pushUrl 会导致沉重的页面栈堆叠和复杂的数据回传。
• 实现方案：在 FlightConcentrator 主入口构建了一个全局状态机 @State currentPage: number (涵盖 0~9 共 10 种视图状态)。
• 优势：通过根节点的 Stack 配合条件渲染 (if-else) 动态挂载 @Builder 视图组件。不仅实现了页面间的零延迟丝滑切换，更让临时航程数据（如 tempStartTime, selectedAirport）能在内存中天然共享，彻底免除了跨页传参的开销。
2. 跨容器混合渲染：ArkWeb 与地图动态注入
路线选择界面并未采用静态图片，而是通过 webview.WebviewController 深度集成了高德地图（AMap）的 Web API。
• 动态 HTML 编译：通过 generateMapHtml() 方法，利用 ArkTS 强大的字符串插值能力，实时读取计算出的 candidateAirports 数组。
• 坐标映射与绘制：在内存中拼接出包含特定机场坐标（Lng/Lat）、不同解锁状态的定制化 Marker（标记）点，以及从出发地（CAN）到各候选机场的动态虚线航迹（Polyline），最后通过 loadData() 一次性注入到 Web 组件中。实现了原生系统与复杂 Web GIS（地理信息系统）的完美无缝协同。
3. 数据持久化策略：ArkData Preferences
针对轻量级但高频读取的配置与资产数据，我们采用了系统级的首选项存储方案。
• 快照同步机制：封装了统一的 loadAllData() 和 saveAllData() 接口。无论是完成一次飞行、购买一架飞机还是删除一项计划，都会触发全量快照保存至本地 XML/SQLite 文件中。
• 复杂对象的序列化：对于航班计划 scheduleList、拥有机队 ownedPlanes 等复杂数组结构，巧妙利用 JSON.stringify() 与 JSON.parse() 进行字符串化与反序列化，确保应用在彻底杀进程后，重启依然能百分之百还原现场。
4. 异步计时与生命周期管控
• 定时器降级处理：在“执飞 (FlyingView)”视图中，利用 setInterval 驱动核心的毫秒级倒计时。
• 状态熔断：在执行“紧急返航”或倒计时归零的瞬间，严谨地执行 clearInterval(this.timerId) 进行资源释放，防止内存泄漏。同时，将预期收益（expectedProfit）异步核算并累加至总资金盘，随后驱动状态机返回主面板。
￼
✨ 极致的 UI/UX 设计亮点 (Design Aesthetics)
代码之外，我们追求的是极客与美学的交融。本项目摒弃了传统的扁平化（Flat Design），全面拥抱现代玻璃拟态学 (Glassmorphism)。
• 深空视界背景：全应用底层铺设了一张通过 LinearGradient 绘制的深蓝渐变画布（#0f2027 至 #2c5364），隐喻从深夜的停机坪直抵三万英尺的平流层。
• 全局毛玻璃算法：通过自定义的 ArkTS @Styles function glassEffect() 混入（Mixin），赋予所有卡片、列表和模态弹窗灵魂：
• 使用 rgba(255, 255, 255, 0.12) 作为极低透明度基底。
• 配合强大的 .backdropBlur(25) 背景高斯模糊渲染，使底层星空色彩自然透出。
• 辅以 .border 高光白线描边与柔和的 shadow 阴影投影，塑造出悬浮于空间中的高科技“全息投影玻璃”质感。
• 交互式品牌专区：在飞机商店模块，不仅对左侧的真实 Logo 进行了去白底融合处理，更针对三大厂牌定制了专属的卡片流光溢彩过渡色（如商飞的红金渐变、波音的科技蓝渐变），极大增强了收集养成的视觉刺激。

🛠️ 本地编译与运行指南 (Deployment Instructions)
要将这座“机场”在你的设备上跑起来，你无需配置复杂的后端环境，本项目为纯鸿蒙原生端侧应用。
1. 环境依赖
• 必须使用华为官方 IDE：DevEco Studio (建议使用 4.0 Release / API 10 或 HarmonyOS 5.0 NEXT 以上版本)。
• 安装对应版本的 HarmonyOS SDK。
2. 源码克隆
• 在终端执行：git clone https://github.com/你的用户名/Flight-Concentrator.git
3. 加载与编译
• 启动 DevEco Studio，选择 Open Project，指向被克隆的项目根目录。
• IDE 会自动触发 Gradle / Hvigor 构建流程，并自动执行 ohpm install 拉取必要的依赖项。
4. 引擎点火
• 配置本地 Emulator（模拟器）或连接开启了开发者模式的 HarmonyOS 真机设备。
• 点击 IDE 右上角的绿色三角形 Run 'entry' 按钮。
• 等待 HAP 包构建与推流完成，即可开启你的专注航程。
